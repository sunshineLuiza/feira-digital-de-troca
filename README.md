# Feira digital de troca
## Apresentação do projeto

## DESCRIÇÃO...
*O projeto apresentado busca fornecer um site proprio para a troca, emprestimo e, claro, devolução de itens, com opções para informar o estado de conservação do item, nome, categoria,*
*disponibilidade e descrição, com resumo, pesquisa com filtro e itens cadastrados.*

## TECNOLOGIAS UTILIZADAS...
*Durante o desenvolvimento do projeto, foi utilizado HTML, CSS, JavaScript, eventos, DOM, funções e Local Storage.*
